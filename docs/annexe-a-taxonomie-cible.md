# Annexe A - Taxonomie cible Maison 216

## 1. Role de cette annexe

Cette annexe traduit la vision du masterplan en architecture catalogue exploitable.

Elle sert a:

- normaliser l'offre Maison 216
- structurer la navigation
- preparer les pages SEO
- alimenter le futur builder guide
- definir ce qui releve du catalogue, de la composition et du sur mesure

Ce document doit etre considere comme la reference taxonomique du projet.

## 2. Principes structurants

### 2.1 Une taxonomie a 5 couches

L'offre Maison 216 doit etre organisee selon 5 couches distinctes:

1. univers
2. type de meuble
3. collection
4. composition / bundle
5. projet sur mesure

Ces couches ne doivent pas etre fusionnees.

### 2.2 Regle critique

Un nom commercial comme `Lora`, `Sarra`, `Kent` ou `Bel Air` ne doit plus servir de categorie primaire.
Ce sont des **collections** ou des **compositions**, pas des categories coeur.

### 2.3 Regle UX

Le visiteur doit toujours pouvoir entrer:

- par besoin de piece
- par type de meuble
- par style / collection
- par projet sur mesure

## 3. Taxonomie cible de niveau 1

## 3.1 Univers principaux

Les entrees de niveau 1 recommandees sont:

1. Menuiserie bois
2. Menuiserie Alu
3. Fabrication metallique
4. Sur Mesure
5. Meubles
6. Guides
7. Devis
8. Contact

## 3.2 Raison de ce choix

- il separe clairement les metiers atelier des meubles commandables
- il soutient le SEO transactionnel
- il permet une navigation desktop en deux niveaux, plus aeree et plus lisible
- il permet ensuite de brancher des sous-categories et des collections
- il evite de melanger produit catalogue, projet sur mesure et demande de devis dans un seul tunnel

## 6. Couche "collections"

## 6.1 Definition

Une collection represente une coherence de style, de finition ou de famille commerciale.

Exemples:

- Kent
- Lora
- Sarra
- Janne
- Alma

## 6.2 Regles

- une collection peut contenir plusieurs produits
- une collection peut traverser plusieurs types de meuble
- une collection peut porter une narration de style
- une collection peut exposer une ou plusieurs compositions pretes

## 6.3 Ce qu'une collection n'est pas

- ce n'est pas une categorie mere
- ce n'est pas un substitut de navigation principale
- ce n'est pas un simple tag marketing vide

## 7. Couche "compositions / bundles"

## 7.1 Definition

Une composition est une offre structurée vendant plusieurs elements compatibles.

Exemples:

- chambre adulte 3 elements
- chambre adulte 5 elements
- salon TV + table basse + buffet
- salle a manger table + 6 chaises + buffet

## 7.2 Types de compositions

- composition prete a acheter
- composition editable a partir d'une base
- composition inspiration sans achat direct

## 7.3 Usage

Les compositions servent:

- la conversion
- l'upsell
- la clarté
- le builder guide

## 8. Couche "builder / composer"

## 8.1 Entrees MVP recommandees

Le MVP ne doit pas couvrir tout le catalogue.

Parcours a lancer en priorite:

1. Composer une chambre adulte
2. Composer une chambre enfant
3. Composer un salon
4. Composer un dressing
5. Composer une cuisine modulaire

## 8.2 Logique d'entree par templates

Chaque builder doit commencer par un template.

Exemples chambre adulte:

- essentielle
- confort
- complete
- premium

Modules possibles:

- lit
- tables de nuit
- commode
- armoire
- coiffeuse

## 8.3 Regles non negociables

- pas de page vide
- pas de personnalisation libre infinie
- pas de modules incompatibles affiches ensemble

## 9. Couche "sur mesure"

## 9.1 Projets sur mesure prioritaires

- cuisine sur mesure
- dressing sur mesure
- bibliotheque sur mesure
- meuble TV sur mesure
- placard sous pente
- aluminium
- ferronnerie

## 9.2 Difference avec les compositions

Une composition cherche a convertir un panier ou une estimation simple.
Un projet sur mesure cherche a qualifier un besoin reel et a lancer un flux commercial.

## 11. Regles de nommage

## 11.1 Regles categories

- nom court
- terme recherche par les utilisateurs
- pas de virgules inutiles
- pas de slash si evitable
- pas de formulation floue

Preferer:

- `Armoires & dressings`
- `Meubles TV`
- `Meubles bas cuisine`

Eviter:

- `Armoires, dressings, placards`
- `Meubles TV & supports TV` si `supports TV` n'est pas une vraie gamme

## 11.2 Regles collections

- nom de collection conserve
- page dediee
- URL simple

Exemple:

- `Collection Kent`
- slug: `kent`

## 11.3 Regles compositions

Formule recommandee:

`<piece> + <nombre d'elements> + <collection ou style>`

Exemples:

- `Chambre adulte 4 elements Kent`
- `Salon TV 3 elements chene & noir`
